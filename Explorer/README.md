<h2 id="نظرة-عامة"> 
  <img src="https://api.iconify.design/mdi:eye-outline.svg?color=%23D60201" width="24" height="24" align="center" /> نظرة عامة
</h2>

**محوّل الألوان** هو تطبيق ويب خفيف ومستقل، مبني بواجهة تفاعلية تتيح للمصممين والمطورين استكشاف عالم الألوان بسهولة. كل ما عليك فعله هو إدخال اللون بأي صيغة، لتتوالى عليك النتائج من تحويلات، وفحوصات للتباين، وتناغمات لونية، مع واجهة تتغير ديناميكياً لتعكس اللون الذي تختاره.

<h2 id="الميزات-الرئيسية"> 
  <img src="https://api.iconify.design/mdi:star-circle-outline.svg?color=%23D60201" width="24" height="24" align="center" /> الميزات الرئيسية
</h2>

| الميزة | الوصف | الأيقونة |
| :--- | :--- | :---: |
| **تحويل شامل** | يدعم جميع صيغ الألوان بدقة (HEX, RGB, HSL, CMYK، والأسماء القياسية). | <img src="https://api.iconify.design/mdi:swap-horizontal.svg?color=%23D60201" width="20" /> |
| **تفاعل ديناميكي** | واجهة ذكية تتغير ألوانها وعناصرها فوراً لتعكس اللون الذي تختاره. | <img src="https://api.iconify.design/mdi:magic-staff.svg?color=%23D60201" width="20" /> |
| **تحكم في الشفافية** | شريط تفاعلي يمنحك التحكم الكامل في درجات الشفافية (Alpha). | <img src="https://api.iconify.design/mdi:opacity.svg?color=%23D60201" width="20" /> |
| **فحص التباين** | أداة تقيس مدى توافق اللون مع معايير الوصول العالمية (AA و AAA). | <img src="https://api.iconify.design/mdi:contrast-circle.svg?color=%23D60201" width="20" /> |
| **التناغم اللوني** | استخراج أنظمة ألوان احترافية (متكاملة، ثلاثية، رباعية) لتصميم واجهات متناسقة. | <img src="https://api.iconify.design/mdi:vector-combine.svg?color=%23D60201" width="20" /> |
| **سهولة الاستخدام** | تصميم متجاوب وسريع يدعم الهواتف والكمبيوتر مع ميزة النسخ الفوري. | <img src="https://api.iconify.design/mdi:cellphone-link.svg?color=%23D60201" width="20" /> |

<h2 id="الصيغ-المدعومة"> 
  <img src="https://api.iconify.design/mdi:format-color-fill.svg?color=%23D60201" width="24" height="24" align="center" /> الصيغ المدعومة
</h2>

| الصيغة | مثال | الوصف |
| :--- | :--- | :--- |
| **HEX** | `#D60201` | النظام الست عشري القياسي |
| **RGB / RGBA** | `rgb(214, 2, 1)` | الأحمر، الأخضر، الأزرق، والشفافية |
| **HSL / HSLA** | `hsl(0, 98%, 42%)` | تدرج اللون، التشبع، والإضاءة |
| **HSV / HSVA** | `hsv(0, 99%, 84%)` | تدرج اللون، التشبع، والقيمة |
| **HWB** | `hwb(0 1% 16%)` | تدرج اللون، البياض، والسواد |
| **CMYK** | `cmyk(0%, 99%, 100%, 16%)` | السماوي، الأرجواني، الأصفر، والأسود |
| **أسماء CSS** | `tomato` | أسماء الألوان القياسية في CSS |

<h2 id="البدء-السريع"> 
  <img src="https://api.iconify.design/mdi:rocket-launch-outline.svg?color=%23D60201" width="24" height="24" align="center" /> البدء السريع
</h2>

التطبيق لا يحتاج إلى أي خوادم أو تثبيت حزم (No Build Step). فقط قم بالآتي:

1. قم بتحميل ملفات المشروع من مجلد [`Explorer`](https://github.com/T7-T7/BOT-STEAM/tree/main/Explorer).
2. تأكد من وجود الملفات في نفس المجلد.
3. افتح ملف `index.html` مباشرة في أي متصفح حديث (Chrome, Safari, Firefox).
