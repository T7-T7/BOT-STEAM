# 🤖 STEAM-V2

بوت واتساب للمجموعات يحتوي على أدوات إدارية، ألعاب، أرشيف، بحث ديني، وحالة المجموعة.



## 📋 الأوامر

### 🧪 عام

| الأمر | الوظيفة |
|---|---|
| `.تست` | التأكد من أن البوت يعمل وعرض سرعة الاستجابة. |
| `.اوامر` | عرض أقسام وأوامر البوت. |
| `.اعداد` | إعدادات البوت — للمطور فقط. |



### 🛡️ إدارة المجموعة

| الأمر | الوظيفة |
|---|---|
| `.رفع ادمن` | رفع شخص إلى مشرف في المجموعة. |
| `.ازل ادمن` | إزالة الإشراف من شخص. |
| `.طرد` | طرد شخص من المجموعة باستخدام ريبلاي أو منشن أو رقم. |
| `.خروج` | إخراج البوت من المجموعة — للمطور فقط. |
| `.دليت` | حذف رسالة. |
| `.تغيير` | تغيير اسم المجموعة. |

**مثال:**


.تغيير قروب FIX

تغيير صورة المجموعة:

.غير صوره

استخدم الأمر مع ريبلاي على الصورة.




📢 البوست

الأمر	الوظيفة

.بوست	نشر نص أو صورة أو فيديو كحالة للمجموعة.


نص:

.بوست اهلا بكم

صورة أو فيديو:

استخدم .بوست مع ريبلاي على الصورة أو الفيديو.




🎵 الصوت

الأمر	الوظيفة

.صوت	البحث عن صوت وتحميله كفويس.


مثال:

.صوت سورة الفاتحة المنشاوي




📂 الأرشيف

الأمر	الوظيفة

.ارشيف	إنشاء ملف داخل الأرشيف.
.ت	عرض محتوى ملف من الأرشيف.
.اضف	إضافة رسالة أو محتوى إلى الأرشيف.


إنشاء أرشيف:

.ارشيف-جداول-[جدول يوم]

عرض أرشيف:

.ت جداول

إضافة رسالة بالريبلاي:

.اضف جداول

استخدم الأمر مع ريبلاي على الرسالة.

إضافة محتوى مباشرة:

.اضف-جداول-[يوم ثاني]




🌙 الدرر السنية

الأمر	الوظيفة

.درر حديث	البحث عن حديث في موقع الدرر السنية.
.درر تفسير	البحث عن تفسير آية أو سورة.


البحث عن حديث:

.درر حديث "جزء من الحديث"

اكتب جزءًا من الحديث داخل "".

البحث عن تفسير:

.درر تفسير آية الكرسي




🎮 الألعاب

الأمر	الوظيفة

.xo	لعبة XO.
.بنج	لعبة Pong.
.شطرنج	لعبة شطرنج.
.اركيد لعبة جيده.





⚙️ النظام

الأمر	الوظيفة

.سيستم	عرض ملفات البوت.
.سيستم <رقم>	عرض الملف الموجود في الرقم المحدد.
.سيستم al	تجهيز نسخة نظيفة من ملفات البوت بدون بيانات التشغيل.


عرض ملف برقم:

.سيستم 1

يعرض الملف المرتبط بالرقم 1.

تجهيز نسخة نظيفة:

.سيستم al




🔐 الصلاحيات

بعض الأوامر مخصصة للمطور أو تتطلب صلاحيات إدارية داخل المجموعة.

> ⚠️ لا تحاول استخدام الأوامر المقيدة بدون الصلاحية المطلوبة.






🚀 التشغيل

بعد تجهيز المتطلبات وتشغيل البوت، يمكن استخدام أوامره مباشرة داخل مجموعات واتساب.




📝 ملاحظات

STEAM-V2 مخصص للعمل داخل المجموعات.

بعض الأوامر تعتمد على الريبلاي على رسالة أو صورة أو فيديو.

أوامر الإدارة تتطلب أن يكون البوت قادرًا على تنفيذ الإجراء داخل المجموعة.

الأوامر المقيدة بالصلاحيات لا تعمل للمستخدمين غير المصرح لهم.
