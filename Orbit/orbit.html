مقدمة

توضح هذه السياسة كيفية تعامل Orbit مع بياناتك. نحترم خصوصيتك ونلتزم بحماية معلوماتك — لا نجمع، لا نرسل، لا نشارك أي شيء مع أي طرف ثالث.

ما لا نفعله
  • لا نجمع بيانات شخصية — لا اسم، لا إيميل، لا شيء
  • لا نملك سيرفرات — لا مكان نخزن فيه بياناتك
  • لا نستخدم تحليلات — لا Google Analytics ولا غيرها
  • لا نستخدم كوكيز تتبع — لا شيء من هذا القبيل
  • لا نشارك بياناتك — لأننا أساسًا لا نملكها
التوكن الخاص بك
  • يبقى في ذاكرة المتصفح فقط افتراضيًا
  • يُرسل فقط إلى api.github.com — ولا مكان آخر
  • يُشفَّر قبل حفظه محليًا (إن اخترت "تذكرني")
  • يمكنك مسحه في أي وقت بضغطة واحدة
ما يُخزَّن محليًا
  • سجل العمليات — يمكنك حذفه من هذا القسم
  • تفضيلات المظهر (ليلي / نهاري)
  • المستودع النشط
  • التوكن المشفّر (إن فعّلت التذكر)
تحقق بنفسك
  • افتح DevTools → Network
  • سترى أن الاتصالات كلها إلى api.github.com فقط
  • الكود مفتوح بالكامل — راجعه بنفسك
تنبيه أمني

احرص على استخدام جهاز موثوق عند تفعيل "تذكر التوكن". يُفضَّل استخدام Fine-grained Token مقيّد بمستودع واحد لتقليل المخاطر.

آخر تحديث

آخر تحديث للسياسة: 2026. أي تغييرات ستظهر هنا تلقائيًا.

قبول الشروط

باستخدامك تطبيق Orbit، فإنك توافق على هذه الشروط. إن لم تكن موافقًا، يرجى التوقف عن الاستخدام.

وصف الخدمة

Orbit أداة مفتوحة المصدر تعمل بالكامل في متصفحك للتفاعل مع GitHub API. لا تتطلب تسجيلًا، ولا تملك سيرفرات، ولا تجمع أي بيانات.

الترخيص (MIT)
  • يُسمح بـ الاستخدام التجاري
  • يُسمح بـ التعديل والتوزيع
  • يُسمح بـ الاستخدام الخاص
  • بشرط الاحتفاظ بحقوق النشر والترخيص
مسؤولياتك
  • أنت المسؤول الوحيد عن المحتوى الذي ترفعه إلى GitHub
  • أنت المسؤول عن حماية التوكن الخاص بك
  • الالتزام بـ شروط استخدام GitHub وسياساتها
  • عدم استخدام الأداة في أي نشاط مخالف للقانون
  • عدم محاولة إساءة استخدام خدمة GitHub عبر هذه الأداة
حدود المسؤولية
  • البرنامج يُقدَّم "كما هو" بدون أي ضمانات
  • لا نضمن عدم انقطاع الخدمة أو خلوها من الأخطاء
  • لا نتحمل مسؤولية فقدان بيانات أو أضرار ناتجة عن الاستخدام
  • لا نتحمل مسؤولية أي إجراء يتخذه GitHub على حسابك
  • استخدامك للأداة على مسؤوليتك الكاملة
التعويض

أنت توافق على تعويض مطوّر Orbit وإبراء ذمّته من أي مطالبات أو أضرار تنشأ عن استخدامك للأداة أو انتهاكك لهذه الشروط.

الإنهاء

يمكنك التوقف عن استخدام Orbit في أي وقت. لا حاجة لأي إجراء — فقط أغلق الصفحة أو امسح البيانات المحلية.

التعديلات

قد تُحدَّث هذه الشروط مستقبلًا. استمرارك في استخدام التطبيق بعد التحديث يُعدّ موافقة ضمنية على الشروط الجديدة. آخر تحديث: 2026.

الإعداد
كيف أحصل على التوكن؟
اذهب إلى github.com/settings/tokens → Generate new token → اختر الصلاحية repo → انسخ التوكن والصقه.
لماذا لا أرى مستودعاتي؟
بعد التحقق، يتم جلب كل مستودعاتك تلقائيًا. اضغط "تحديث" إن لم تظهر، وتأكد أن التوكن فيه صلاحية repo.
هل يجب أن أحفظ التوكن؟
لا — اختياري. بدونه يُمسح عند إغلاق الصفحة. معه يُحفظ 30 يومًا — للأجهزة الشخصية فقط.
الرفع
كيف أرفع مشروعًا كاملًا؟
  • اختر مستودعًا من قسم الرفع
  • "اختر مجلد" → اختر مجلد المشروع
  • اترك "المسار" فارغًا للرفع في الجذر
  • اضغط "ابدأ الرفع"
هل يُرفع node_modules و .git؟
لا — تُستثنى تلقائيًا: .git، node_modules، dist، build، وغيرها.
ما فائدة الرفع كـ ZIP؟
يضغط كل الملفات المحددة في ملف .zip واحد ويُرفعه في commit واحد. أسرع بكتير لو عندك مئات الملفات الصغيرة.
التحكم
كيف أنقل ملفًا أو مجلدًا؟
اضغط زر "نقل" على أي ملف/مجلد → اختر المستودع والمجلد الهدف → "إفلات هنا".
هل يمكنني إعادة تسمية مجلد؟
نعم — اضغط زر ✏️ على المجلد → اكتب الاسم الجديد → تعديل. سيتم تحديث كل المسارات داخله تلقائيًا.
ما يميز Orbit
لماذا أستخدم Orbit بدل GitHub؟
  • رفع مجلد كامل بضغطة
  • لا git ولا terminal — واجهة بصرية 100%
  • كل شيء في صفحة واحدة
  • محرر مدمج بكل اللغات
  • نسخ / نقل / إعادة تسمية
  • رفع ZIP للمشاريع الكبيرة
  • أرشيف محلي مع تصدير JSON
  • ثيم ليلي ونهاري
